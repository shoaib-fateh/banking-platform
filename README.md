# Horizon Banking Platform

Horizon is a modern banking platform built with **Next.js 14**, **React**, **TailwindCSS**, and integrated with **Plaid** for seamless financial data handling.

## Features
- Secure Authentication
- Financial Data Integration with Plaid
- Real-time Analytics
- Responsive Design

## Getting Started
```bash
npm run dev
# or
yarn dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment
Easily deploy on [Vercel](https://vercel.com/).

## Tech Stack
- Next.js 14
- React
- TailwindCSS
- Plaid
